Este arquivo existe apenas para preservar links e rotas antigas.

A definição vigente de `/id` está em **`comandos.md` v1.7.0 ou posterior**.

Regra atual:
- `/mpe`, `/mpe+` e `/mpe-` **já geram cabeçalho automaticamente**;
- portanto, `/id` não é necessário junto com a família MPE;
- `/id` serve para forçar cabeçalho de proveniência **fora** da família MPE;
- `/id off` desativa o cabeçalho quando solicitado;
- falta de plataforma, modelo, título ou ID não autoriza omitir o cabeçalho: usar marcador de indisponibilidade;
- se este arquivo divergir de `comandos.md`, prevalece `comandos.md`.

Não reutilizar definições históricas anteriores deste arquivo como regra ativa.
